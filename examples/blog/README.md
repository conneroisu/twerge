# Blog Example

This example demonstrates a basic blog interface built with twerge and Tailwind CSS.

## Features
- Simple layout with header and footer
- Article list with blog posts
- Uses twerge for optimized Tailwind class management

## Setup and Running
1. Generate the templ components:
```sh
templ generate ./views
```
2. Run the code generation:
```sh
go run gen.go
```
3. Run the server:
```sh
go run main.go
```
4. Open your browser and navigate to http://localhost:8080
